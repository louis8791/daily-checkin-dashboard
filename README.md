# 八週行動紀錄儀表板

這是一個規劃中的私人行動紀錄網頁。管理者每天貼上群組接龍，系統即時整理 10 人在八週內的完成次數、達成率、圖表與 PDF；群組成員可在手機或電腦唯讀查看。

> 本資料用於鼓勵持續行動，不作為強制要求或考核依據。

## 目前狀態

目前已完成只含假名的 Phase 1 可操作原型：可查看總覽、每週、個人進度與每日匯入，並以瀏覽器列印功能匯出目前畫面 PDF。正式登入、加密、雲端部署與真實資料匯入仍未完成。

## 本機預覽

在 `E:\打卡\repo` 啟動簡易本機伺服器後開啟 `http://127.0.0.1:4173/`。自動化邏輯檢查可執行：

```powershell
node scripts/self-check.mjs
```

每日頁的示範輸入只接受固定假名；請勿貼入真實姓名。PDF 按鈕會開啟瀏覽器列印／另存 PDF，正式五種報表與手機下載流程列在 Phase 3。

## 核心原則

- 正式產品不使用 AI 模型或 AI API。
- 真實姓名不進提示詞、公開 Git、CI、log、分析或錯誤回報。
- 公開 repo 只使用假名與合成資料。
- 真實資料與公開 source repository 實體分離。
- 群組入口唯讀且受密碼保護；管理者入口使用獨立權限。
- PDF 在使用者瀏覽器產生，不呼叫外部 AI 或 PDF 轉換服務。

## 公開範圍檢查

提交前執行：

```powershell
pwsh -File scripts/check-public-scope.ps1
```

如果檢查失敗，不得用刪掉檢查或改名的方式硬推；先確認檔案是否屬於私人資料並移回 repo 外。
